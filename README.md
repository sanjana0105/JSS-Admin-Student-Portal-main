# JSS Admin Student Portal

A full stack web application with Admin and Student portals built using **Angular, Java Spring Boot, and PostgreSQL**. Developed for managing student data and interactions.

## Features
- Admin portal to manage student records
- Student portal for viewing grades and assignments
- File uploads (Lesson Plans, Question Banks, Markscards)
- Secure authentication and role-based access

## Technologies
- Frontend: Angular
- Backend: Java Spring Boot
- Database: PostgreSQL
